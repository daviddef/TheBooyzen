# The outbox — nine letters written, none sent

**Checked 11 October 2026.** Every letter below is finished prose with the references
already found. None of them needs research; each needs a send. **The oldest has been
sitting for twenty-seven days.**

This file exists because the bottleneck in this archive stopped being research some
time around 21 September. On that date the work had produced ten drafted requests. On
11 October it had produced ten drafted requests, two of them since revised, and nothing
had gone out. **The research is not the thing standing between this family and these
documents. The sending is.**

## How to send one

Each file has a `---` rule in it. **Everything above the rule is for us** — why the letter
exists, what it is worth, what to do with a reply. **Everything below it is the letter**,
beginning with its `**Subject:**` line. Copy from the subject line down, paste into mail,
send. Nothing needs rewriting.

When one goes, change its `**Status:**` line to `SENT <date>` and set the matching row in
`site/src/data/letters.json` to `sent`. **Those two must not drift apart** — this file
exists partly because they did.
